# 🔢 Pattern Generator and Number Analyzer

A beginner-friendly **Python console application** that combines **pattern generation** and **number analysis** in one menu-driven program.

This project is designed to practice fundamental Python concepts such as **loops, nested loops, `range()`, conditional statements, and control statements** like `break`, `continue`, and `pass`.

---

## 📌 Project Overview

The **Pattern Generator and Number Analyzer** provides two main functions:

### ⭐ 1. Pattern Generator

Generates a **right-angled triangle pattern** based on the number of rows entered by the user.

Example:

```text
*
**
***
****
*****
```

### 🔢 2. Number Analyzer

Analyzes a user-defined range of numbers and:

* Determines whether each number is **Odd or Even**
* Calculates the **sum of all numbers** in the range

Example:

```text
Enter the start of the range: 10
Enter the end of the range: 15

Number 10 is Even
Number 11 is Odd
Number 12 is Even
Number 13 is Odd
Number 14 is Even
Number 15 is Odd

Sum of all numbers from 10 to 15: 75
```

## 🧠 Python Concepts Used

This project focuses on the following concepts:

| Concept          | Purpose                                     |
| ---------------- | ------------------------------------------- |
| `for` loop       | Iterating through rows and numbers          |
| `while` loop     | Repeating the menu and input process        |
| Nested loops     | Generating the triangle pattern             |
| `range()`        | Creating a sequence of numbers              |
| `if-else`        | Checking odd/even conditions                |
| `%` operator     | Determining whether a number is odd or even |
| `break`          | Stopping a loop                             |
| `continue`       | Skipping an iteration                       |
| `pass`           | Placeholder for future logic                |
| Variables        | Storing input and calculated values         |
| Input validation | Handling invalid user input                 |
